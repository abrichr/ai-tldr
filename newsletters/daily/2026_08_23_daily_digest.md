<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">SGLang v0.5.18 — cold starts get 2.38x faster, seven model families land</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">SGLang v0.5.18 overlaps weight loading with CUDA graph capture, cutting a large-model cold start from 85 seconds to 36.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
SGLang v0.5.18 overlaps checkpoint staging with CUDA graph capture so a Qwen3-32B server on an H100 starts in 35.6 seconds instead of 84.8. Seven new model families — including Muse Glimmer, SANA-Video, and LTX-2.5 — gain serving support.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Pass <code style="font-family: Menlo, Consolas, monospace; font-size: 13px;">--startup-weight-load-mode overlap</code> to stage weights from storage in parallel with graph capture. A separate all-to-all attention path cuts the tensor-parallel LMHead decode step from 320 to 169 microseconds.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Restart time is a real operational cost: autoscaling, rolling upgrades, and crash recovery all pay it. Halving startup time makes a large-model serving fleet cheaper to move around.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Inference and platform engineers self-hosting open-weight models who need fast, cost-efficient restarts.

Admins also gain a per-user <code style="font-family: Menlo, Consolas, monospace; font-size: 13px;">memory_policy</code> to control which memory types can be extracted for a specific person.

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Remote Skills are discovered and cached before VikingBot runs them, so a long agent session doesn't refetch them at every step. Resource imports with <code style="font-family: Menlo, Consolas, monospace; font-size: 13px;">wait=false</code> now move source preparation into a restartable background task, lowering request latency.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>

</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

Teams running shared agent memory across multiple OpenViking deployments.

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">OpenRouter Image Benchmarks — 39 image models on one page of hard prompts</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Every image model OpenRouter hosts, run through the same hard prompts, with the raw outputs shown in one grid.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
OpenRouter Image Benchmarks is a free public page that runs the same deliberately hard prompts through all 39 image models on the platform and shows the actual outputs side by side. No account needed.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Prompts cover seven challenge families — improbable scenes, counting, text rendering, spatial relations, negation, editing, and consistency — targeting known weak spots. The grid sorts by cost or generation time, spanning roughly $0.006 to $0.25 per image.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
OpenRouter notes that "LLM-as-a-judge evals can't yet capture the details a human would notice," so the page shows raw output rather than scores. You see what $0.006 vs $0.25 per image actually buys before committing.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Developers and designers choosing an image generation model and wanting a side-by-side visual comparison before committing to a provider.
</p>
